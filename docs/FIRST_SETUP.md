# 처음 설정하기 (웹 설정 페이지)

AI Character를 처음 실행하면 **브라우저에 설정 페이지가 자동으로 한 번 열립니다.**
왼쪽 목록을 위에서부터 따라가며 채우고, 각 단계의 **저장하고 다음 →** 을 누르면 앱에 바로 저장됩니다.

## 다시 열고 싶을 때

- 메뉴 막대(Windows는 작업 표시줄 오른쪽)의 AI Character 아이콘 → **처음 설정 (웹)**
- 또는 캐릭터 우클릭 → 설정 → **시작** 탭 → **웹에서 쉽게 설정하기**

> 페이지 주소는 `http://127.0.0.1:17321/` 이고, 이 컴퓨터에서만 열립니다.
> 앱이 꺼지거나 재시작되면 페이지 위에 "연결이 끊겼습니다" 띠가 뜨고, 앱이 다시 켜지면 **자동으로 다시 연결**됩니다.
> "로그인이 만료되었습니다"가 보이면 위 방법으로 다시 열면 됩니다.

## 누가 먼저 하나요

1. **대화** — ChatGPT 구독이 답합니다.
2. **정보 찾기** — 무료 Gemini가 찾습니다.
3. **파일 고치기** — Claude가 계획하고 고칩니다. Cursor도 고칠 수 있습니다. 플러그인은 Claude에 붙습니다. 둘 다 없으면 다른 설치 프로그램이 나눕니다.
4. **유료 API** — 꺼져 있습니다. 사용량을 다 쓰면 채팅에 알려 줍니다.

처음 설정은 추천 설정, 작업 폴더, Gemini 키만 하면 됩니다.

Claude에 플러그인을 여러 개 다는 방식이 맞습니다. 그 도구는 파일을 고칠 때 함께 켜집니다.

## 단계별로 하는 일

| 단계 | 하는 일 | 꼭 해야 하나 |
| --- | --- | --- |
| 1. 시작하기 | 현재 상태 확인, **추천 설정 한 번에 적용** | 추천 |
| 2. 작업 폴더 | AI가 읽고 고칠 프로젝트 폴더 선택 | ⭕ |
| 3. AI 연결 | Gemini 무료 키 등록 (1분). 인터넷 검색을 원하면 Jina 키도 | ⭕ (Gemini 하나) |
| 4. 프로그램 · 로그인 | Claude/Codex 설치 상태 확인, 로그인 버튼 | 구독형을 쓸 때만 |
| 5. 동작 방식 | 무료 자동 모드, 웹 검색, 유료 허용 여부 | 기본값 그대로 OK |
| 6. 알림 · 비용 한도 | 하루 유료 한도(기본 1달러), 데스크톱 알림 | 기본값 그대로 OK |
| 7. 자동 업데이트 | 무엇을 자동 업데이트할지, 배포용 서명 설정 안내 | 기본값 그대로 OK |
| 8. 마무리 · 백업 | 남은 항목 점검, **설정 백업 파일 받기 / 불러오기** | 백업 추천 |

## 가장 빠른 길 (3분)

1. **추천 설정 한 번에 적용** 클릭
2. **작업 폴더** → 폴더 선택… → 프로젝트 폴더 고르기
3. **AI 연결** → Gemini의 "키 받는 곳 열기" → Create API key → 복사 → 붙여넣고 **저장**
4. **마무리** → 설정 완료

## 내 컴퓨터 AI (설치형)

- 왼쪽 메뉴 아래 **💻 내 컴퓨터 AI (설치형)** 에서 따로 관리합니다. API 키 단계와는 분리되어 있습니다.
- 사양은 고정값이 아니라 **앱이 실행 중인 컴퓨터를 그때그때 검사**합니다. 다른 컴퓨터에 앱을 설치하면 그 컴퓨터 기준으로 판정합니다 (Mac: Apple 칩/Intel, Windows: 메모리·NVIDIA 그래픽카드 메모리, Linux: 메모리·NVIDIA).
- 먼저 칩·메모리·모델이 저장될 디스크의 남은 공간·그래픽 가속을 확인하고, 모델마다 **잘 돌아감 / 느릴 수 있음 / 메모리 부족 / 저장공간 부족**으로 판정합니다. 돌릴 수 있는 모델 중 하나에 **추천**이 붙습니다.
- **Ollama 설치**와 **모델 받기**는 버튼을 두 번 눌러야만 시작합니다 (Mac은 공식 앱을 내려받아 응용 프로그램 폴더에 설치, Windows는 winget → 없으면 공식 설치 프로그램, Linux는 설치 명령을 복사해 터미널에서 실행). 다운로드 진행률이 표시되고, 페이지를 닫아도 앱이 계속 받습니다.
- 메모리나 저장공간이 부족한 모델은 받기 버튼이 막혀 있습니다. 받은 모델은 **이 모델 먼저 쓰기**로 우선순위를 정하거나 **삭제**로 공간을 되돌릴 수 있습니다.
- 목록: LG EXAONE 3.5 (2.4B·7.8B·32B), EXAONE Deep 7.8B, Alibaba Qwen3 (4B·8B·14B·30B), Qwen2.5 Coder 7B, DeepSeek R1 8B.

- **저장 위치**: 내장 디스크와 외장하드(USB·추가 드라이브)를 모두 보여 주고, 남은 공간을 보고 골라 저장할 수 있습니다. 판정도 고른 디스크 기준이며, 공간이 부족하면 넉넉한 다른 디스크를 알려 줍니다. 외장하드를 빼면 그동안 설치형 AI만 쉬고 인터넷 AI는 그대로 씁니다.

## 다른 컴퓨터 AI (원격)

- 왼쪽 메뉴 **🌐 다른 컴퓨터 AI (원격)**. 성능 좋은 컴퓨터(A)의 설치형 AI를 노트북 등 다른 컴퓨터(B)에서 빌려 씁니다. 두 컴퓨터 모두 AI Character가 필요합니다.
- A에서: Ollama 설치 → **이 컴퓨터 공유 켜기**(두 번 클릭) → **연결 코드 만들기**. 중계 서버가 있으면 큰 **6자리 숫자**가, 없으면 `AIC1.`로 시작하는 긴 코드가 나옵니다(긴 코드는 복사해 B로 보내기). 둘 다 10분 동안 한 번만 쓸 수 있습니다.
- B에서: **다른 컴퓨터 연결하기**에 6자리 숫자를 입력하거나 긴 코드를 붙여 넣고 **연결하기**. 6자리 숫자는 중계 서버를 거쳐 전달되므로 B에도 같은 중계 서버가 저장돼 있거나, B 카드의 '중계 서버 정보 직접 넣기'에 한 번 넣어야 합니다. 한 번 연결하면 다음부터 자동으로 이어집니다. A의 사양 판정을 보고 A에 모델을 받을 수 있고, 대화 중 인터넷 AI가 막히면 내 컴퓨터 → 다른 컴퓨터 순서로 자동 사용합니다.
- 연결은 iroh로 처음부터 끝까지 암호화됩니다. Ollama는 네트워크에 직접 열리지 않고, 연결 코드로 허락한 컴퓨터만 대화·모델 목록·모델 받기 기능을 쓸 수 있습니다(삭제 등은 막힘). A의 **연결 끊기**로 언제든 막을 수 있습니다.
- 같은 공유기 안에서는 그대로 됩니다. 밖에서도 쓰려면 내 서버에 별도 프로젝트 **AI Character 중계 서버(aic-relay)** 를 한 번 설치하고(소스와 설치 안내: `AI-Character-Relay` 폴더의 README), A의 **밖에서도 쓰기: 중계 서버**에 주소와 접속 암호를 넣은 뒤 연결 코드를 새로 만드세요. 공용 중계 서버는 쓰지 않고 내 서버만 씁니다. 포트포워딩은 필요 없습니다.
- 중계 서버가 있으면 컴퓨터 카드에 **🟢 켜짐 / ⚫ 꺼짐**(마지막 접속 시각)과 **⚡ 직접 연결 / 🔁 중계 서버 경유**(응답 시간)가 표시됩니다. 꺼져 있는 컴퓨터는 연결을 기다리지 않고 바로 알려 줍니다.
- **휴대폰**: 휴대폰 브라우저로 `https://중계서버주소/app`을 열고 접속 암호와 A의 6자리 숫자를 넣으면, 앱 설치 없이 A의 설치형 AI와 대화할 수 있습니다. 대화는 휴대폰과 A 사이에서 암호화되어 중계 서버도 볼 수 없습니다.

## 사용 설명서

- 왼쪽 메뉴 **❓ 사용 설명서**에 5분 시작하기, 메뉴별 설명, AI 사용 순서, 단어 풀이, 자주 묻는 질문을 처음 쓰는 분 기준으로 모아 두었습니다. 각 화면 위에도 "처음이라면 이 순서대로" 안내가 있습니다.

## 사용량 보기

- 대화창 위 **사용량** 버튼: 오늘 요약만 보여 줍니다 (오늘 유료 비용과 하루 한도, 오늘 호출 수, 가장 많이 쓴 AI, Claude 오늘 토큰, Codex 한도 %).
- 자세한 내용은 대화창의 **자세히 (웹)**, 메뉴 막대 아이콘의 **사용량**, 캐릭터 오른쪽 클릭 → **사용량** 중 하나를 누르면 웹 설정 페이지의 **📊 사용량 보기**가 열립니다.
- 웹에서는 오늘 / 7일 / 30일을 골라 일별 그래프, AI·모델별 표(성공률·속도·토큰·비용), Claude 구독과 Codex 사용 토큰, 최근 호출 25개를 봅니다. 1분마다 자동으로 새로 고칩니다.
- 숫자는 모두 이 컴퓨터 안의 기록(앱 사용 기록 데이터베이스, `~/.claude`, `~/.codex`)에서 읽습니다. 인터넷으로 조회하지 않고, 유료 API를 부르지도 않습니다.

## 저장과 백업

- 각 단계의 저장 버튼을 누르면 즉시 앱 설정에 저장됩니다. 진행 상황(어디까지 했는지)도 저장되어 다음에 열면 이어서 할 수 있습니다.
- **설정 백업 파일**에는 동작 방식·알림·업데이트·작업 폴더가 들어가고, **API 키는 들어가지 않습니다.** 새 컴퓨터에서는 백업을 불러온 뒤 키만 다시 넣으면 됩니다.
- API 키는 이 컴퓨터의 앱 전용 파일(`keys.env`, 본인만 읽기 가능)에만 저장되며, 설정 페이지는 저장된 키를 다시 보여 주지 않습니다.
